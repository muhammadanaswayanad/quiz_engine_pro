# Product Overview

## Quiz Engine Pro for Odoo 17

A comprehensive quiz engine module for Odoo 17 Community Edition that provides advanced question types and interactive features for educational and assessment purposes.

### Core Purpose
- Create and manage interactive quizzes with multiple question types
- Provide public quiz access without authentication requirements
- Track participant performance and generate analytics
- Support educational institutions and training organizations

### Key Features
- **7 Question Types**: Multiple choice, fill-in-blanks, drag & drop, matching, dropdown, sequence ordering, sentence completion
- **Public Access**: Clean URLs for quiz sharing (`/quiz/slug`)
- **Real-time Scoring**: Automatic evaluation with instant feedback
- **Session Management**: Token-based tracking without user accounts
- **Mobile Responsive**: Touch-friendly interface for all devices
- **Analytics Dashboard**: Performance tracking and reporting

### Target Users
- **Quiz Creators**: Administrators who design and manage quizzes
- **Quiz Takers**: Public users who access quizzes via shared URLs
- **Analysts**: Users who review performance data and reports
